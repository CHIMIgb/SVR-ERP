# 2026-11-14 — B6.1: registros_criba gana maquina_id y proyecto_id (FKs opcionales)

## Qué se hizo

Fase B6.1 (6.4 del plan de IMPLEMENTACIONES-A-FUTURO): los registros de criba
pueden atribuir su producción a una máquina y a un proyecto.

- **`apps/api/prisma/schema.prisma`** — `registros_criba` gana:
  - `maquina_id` (FK a `maquinas`, ON DELETE SET NULL) + índice.
  - `proyecto_id` (FK a `proyectos`, ON DELETE SET NULL) + índice.
  - Back-relations: `maquinas.registros_criba` y `proyectos.registros_criba`.
- **Migración `20261114010000_registros_criba_maquina_proyecto`** — solo lo
  propio (2 columnas, 2 índices, 2 FKs). Aplicada con el método de esta BD
  (`db execute` + `migrate resolve --applied`).
- Ambas **nullable**: los registros previos quedan intactos y el flujo permite
  producción sin máquina/proyecto.
