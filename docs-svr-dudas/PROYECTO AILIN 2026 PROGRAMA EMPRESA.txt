PROYECTO AILIN 2026 PROGRAMA EMPRESA.xlsx
Este Excel es su expediente de UN proyecto: la plantilla de trabajadores con
RFC, domicilio y horario, los camiones con placas/año, y los servicios de
cada unidad. En la aplicación /proyectos llevará esta plantilla por proyecto
(lo de servicios/placas de camiones es de otro módulo y se maneja aparte).

DUDAS (solo lo que toca las vistas):
1. ¿La plantilla de trabajadores de cada proyecto es fija, o la gente cambia
   de proyecto? ¿Quién arma la plantilla?
2. ¿El horario de entrada/salida es de cada proyecto o es el mismo para toda
   la empresa? (vimos horario por persona en la plantilla)
3. ¿El proyecto ES el cliente, o un cliente puede tener varios proyectos?
4. ¿Qué datos se capturan SIEMPRE al abrir un proyecto nuevo (RFC, domicilio,
   horario), y cuáles son opcionales?
5. ¿Para qué usan este expediente: para cobrarle al cliente, para pagar la
   gente del proyecto, o solo control interno? (así la app sabe qué mostrar)

SUGERENCIAS DE MEJORA (lo que la app hará distinto):
- El proyecto trae su gente asignada desde el sistema — ya no es un Excel
  aparte por proyecto.
